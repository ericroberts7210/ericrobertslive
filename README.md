# EricRobertsLive

Home page for Eric Roberts Live (ericrobertslive.com): casual live acoustic music for
porches, wineries, house parties and small rooms.

Plain HTML + CSS, no build step and no dependencies. Hosting: Vercel (Hobby), domain at
GoDaddy.

- `index.html` - the page
- `styles.css` - warm, rustic look (cream, wood tones, orange accent; Fraunces headings)
- `images/hero.jpg` - hero photo; until it exists the page shows a wood-toned placeholder

The song list lives in PickThisPlayThat (https://pickthisplaythat.com/p/eric), which also
shows a "Live Now" banner during a show. Don't duplicate it here.

To preview locally, open `index.html` in a browser.
